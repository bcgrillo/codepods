# About Codepods

Codepods is a self-hosted tool to manage agents, templates, variables, and runtime settings from a unified web UI and CLI.

## Quick Links

- Repository: [lualab-xyz/CodexAgentsManager](https://github.com/lualab-xyz/CodexAgentsManager)
- Issues: [Report an issue](https://github.com/lualab-xyz/CodexAgentsManager/issues)
- License file: [`LICENCE`](./LICENCE)

## Notes

- Host/runtime configuration is managed through `config.toml`.
- Agent build-time substitutions are sourced from the variables table.
- Template files can be managed from the web UI (including upload/download/rename/edit).
